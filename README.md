# talk — 雑談シミュレーションツール

雑談が苦手な人(頭に会話パターンのストックがない人)向けに、**分岐選択式の会話シミュレーション**で雑談を安全に反復練習できるツール。

- 場面: 初対面 / 面識はあるが気を遣う相手 / アイスブレイク
- 「木戸に立てかけし衣食住」の定番テーマから会話を開始し、質問候補の選択 → 相手の返答 → 次の一手候補、と分岐をたどる
- 訓練するのは「相手の返答タイプを認識して次の一手を選ぶ」メタスキル
- まずはローカルPCで動く静的Webアプリ、将来はスマホアプリ化を目指す
