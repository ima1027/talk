# talk — 雑談シミュレーションツール

雑談が苦手な人(頭に会話パターンのストックがない人)向けに、**分岐選択式の会話シミュレーション**で雑談を安全に反復練習できるツール。

- 場面: 初対面 / 面識はあるが気を遣う相手 / アイスブレイク
- 「木戸に立てかけし衣食住」の定番テーマから会話を開始し、質問候補の選択 → 相手の返答 → 次の一手候補、と分岐をたどる
- 訓練するのは「相手の返答タイプ(広がる・返してくる・短い・そっけない)を認識して次の一手を選ぶ」メタスキル
- 静的Webアプリ(オフライン動作・データ送信なし)。将来はスマホアプリ化を目指す

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm test         # エンジン+コンテンツ整合性チェック
npm run build    # 型チェック+本番ビルド(dist/ に静的ファイル)
```

## コンテンツのLLMバッチ増産(開発者向け)

アプリ本体はオフラインの静的データだけで動くが、シナリオの増産にはClaude APIをバッチ利用できる(要件定義書§8のパイプライン)。

```bash
# 認証: ANTHROPIC_API_KEY を設定するか `ant auth login`
npm run generate -- --topic 旅 --scene first_casual --situation "空港の搭乗待合で……"
#  → 生成 → 自動検証(エラーはモデルに差し戻して再生成) → content/drafts/ に保存
#  → 人が監修チェックリストでレビューしてから:
npm run promote -- content/drafts/<id>.json
#  → src/content/scenarios/ に昇格。npm test で最終確認
```

## 構成

| パス | 内容 |
|---|---|
| `src/engine/` | 会話エンジン(状態遷移・重み付きランダム・コンテンツ検証) |
| `src/content/scenarios/*.json` | 会話ツリー(シナリオ)。エンジンとコンテンツは完全分離 |
| `src/components/` | ホーム / シミュレーション / ふりかえり / ツリー閲覧 / 図鑑 / 履歴 |
| `src/lib/` | localStorage永続化・傾向分析・今日の1本の推薦(苦手の再出題) |
| `tools/generate/` | LLMコンテンツ増産パイプライン(生成→検証→監修→昇格) |

シナリオの追加は JSON ファイルを `src/content/scenarios/` に置くだけ。スキーマと必須要件(全終端がきれいな切り上げで終わる、返答カテゴリ3種以上、NG選択肢2つ以上+リカバリ等)は `npm test` で自動検証される。

### シナリオ執筆・レビュー観点(要件定義書 §5.2/§5.3 より)

- NG選択肢は5類型(曖昧質問/プレッシャー質問/話の腰を折る/踏み込みすぎ/タブー直撃)から作り、解説に「なぜまずいか+使い回せる原則」を書く
- 相手の発話はカテゴリの性格が伝わるよう書き分ける(広がる=即座+追加情報、そっけない=間・最小化)
- 選択肢は全角30字目安。場面に応じた敬語レベルを守る

## ステータス

**M3(v1.1)まで実装済み**:

- M1: 会話エンジン、シナリオ選択(今日の1本つき)、シミュレーション画面、ふりかえり画面(ポジティブ2:改善1の総評・別ルート開示・今日試す一手)、コンテンツ整合性の自動チェック
- M2: ツリー閲覧モード(全ルートの予習・復習)、パターン図鑑(使った手本フレーズと技法の収集・技法フィルタ)、履歴と苦手傾向分析、localStorage永続化
- M3: LLMコンテンツ増産パイプライン(`npm run generate` / `npm run promote`)、苦手の再出題(NGが集中した返答カテゴリを多く含むシナリオを「今日の1本」に優先推薦)、テーマ追加で**6テーマ×2場面=12ツリー**(衣・食・天気季節・道楽・旅・ニュース)
- v1.2(ユーザーテスト反映): **複数正解設計**(✕さえ避ければ会話は続く。細い合流点に「もう一手」の復活ルート)、選択直後の即時解説、相手の反応タイプ表示、ターニングポイント分析、partnerNote(相手について知っていること)、未体験の反応タイプ優先
- v1.3(報酬要素): **攻略ランク(C→B→A→S)とエンディング回収**、**称号XP**(雑談見習い→…→雑談の人)、**技法バッジ実績**(図鑑タブ)、**実会話メダル**(「試す一手」を実際の会話で試したら自己申告でメダル化 — 最上位の報酬を現実の行動に置く設計)
- v1.4(キャラクター続編・関係性レベル): 相手を**継続キャラクター化**(釣り好きの上司・野球好きの義父・ボドゲ会のカレー好き)。同じ相手の会話を✕なしクリアすると**関係が育ち(顔見知り→話せる仲→気安い仲)、続編シナリオが解禁**される。続編では前回の会話がコールバックとして活きる。「雑談ができると人間関係が育つ」という現実の報酬構造をそのままゲーム化(調査で唯一の好例だった分岐ナラティブ型 eQuoo と同じ型)。関係データは履歴から決定論的に再計算(保存カウンタなし)

次: M4(PWA/スマホ・伴走モード)、キャラクター続編の拡充(第3話以降)。
